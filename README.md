# Oasis Infobyte — Data Analytics Internship

Welcome to my portfolio of projects completed during the Data Analytics Internship at Oasis Infobyte. 

## Internship Overview
This repository contains the deliverables for five distinct data analytics projects, spread across two levels of difficulty. The tasks span exploratory data analysis, data cleaning, unsupervised learning, regression modeling, and natural language processing.

## Projects

### Level 1
- **Task 1: EDA on Retail Sales Data** (`DataAnalytics-L1-EDARetailSales`)
  - *Description*: Exploratory Data Analysis on retail sales data to uncover purchasing patterns and demographic insights.
- **Task 2: Customer Segmentation Analysis** (`DataAnalytics-L1-CustomerSegmentation`)
  - *Description*: Unsupervised machine learning (K-Means Clustering) applied to RFM metrics to segment customers based on purchasing behavior.
- **Task 3: Cleaning Data** (`DataAnalytics-L1-DataCleaning`)
  - *Description*: A robust pipeline for data preprocessing, handling missing values, outliers, and complex datatypes.

### Level 2
- **Task 4: Predicting House Prices with Linear Regression** (`DataAnalytics-L2-HousePricePrediction`)
  - *Description*: A multivariate Linear Regression model predicting California housing prices based on geography and demographics.
- **Task 5: Unveiling the Android App Market / Google Play Store Analysis** (`DataAnalytics-L2-GooglePlayStoreAnalysis`)
  - *Description*: Comprehensive analysis and NLP (sentiment analysis) of the Google Play Store ecosystem to identify drivers of app success.

## Tools & Skills
- **Python**: Pandas, NumPy, Scikit-Learn, TextBlob
- **Data Visualization**: Matplotlib, Seaborn
- **Machine Learning**: Linear Regression, K-Means Clustering
- **Data Preprocessing & Cleaning**

## Repository Structure
- **`DataAnalytics-*`**: Individual project folders containing source code (`.ipynb`), datasets (`data/`), and output charts (`outputs/`).
- **`presentation/`**: Final interactive HTML presentation slides outlining the projects.
- **`recordings/`**: Final video recordings of the presentations.

## How to Run Notebooks
1. Clone the repository locally.
2. Install the necessary dependencies (e.g. `pip install -r requirements.txt`).
3. Open the `.ipynb` files in Jupyter Notebook or VS Code to review the analysis code.
