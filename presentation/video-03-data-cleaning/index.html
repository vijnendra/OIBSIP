Significant Cleaning Decisions

Methodology
🔤

String Normalization

Problem: 'Sex' column contained 'MALE', 'm', 'male', 'FEMALE', 'f', 'female'.
Method: Mapped to strict lowercase 'male' and 'female'.
Reason: Standardizes categorical feature for future encoding.
🔢

Datatype Correction

Problem: 'Fare' contained '$' symbols, making it an Object type.
Method: Stripped '$' and cast to Float64.
Reason: Enables mathematical operations and statistical analysis.
🏗️

Cabin Feature Engineering

Problem: 'Cabin' was 77% null (730 missing).
Method: Created a new binary feature 'Has_Cabin' (1/0) and filled missing with 'Unknown'.
Reason: Preserves the signal (having a cabin might indicate class/survival) without dropping the column.
📏

Outlier Handling: Age

Validation
📉

Age Distribution (Before)

Anomaly Detection
Impossible Physiological Values
Detected ages of -5.0, 150.0, and 250.0. These represent data entry errors rather than statistical variance.
Correction Method
Neutralize and Impute
Instead of dropping the entire passenger record (losing other valuable data), the anomalous ages were set to NaN. They were then imputed alongside other missing ages using group-based medians.
